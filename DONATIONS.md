# Support the project

This research and education toolkit takes time to maintain. Voluntary support, when available, will help cover development, data access, testing and documentation.

**Stripe support is not active yet.** A verified Stripe-hosted payment link will appear here only after the ecosystem has been completed, its end-to-end behavior reviewed, and the public release is ready. No wallet address or payment instruction elsewhere in this repository should be treated as an official request.

Support does not buy trading advice, private signals, account management, faster access or influence over research conclusions. The project does not claim charitable or tax-deductible status.

The planned flow uses a Stripe Payment Link so payment details stay on Stripe's hosted page; this repository will not collect card data or store Stripe API keys. The maintainer activation steps are in [Stripe support setup](docs/STRIPE_SUPPORT_SETUP.md).
