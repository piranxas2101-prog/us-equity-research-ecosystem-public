# Επόμενη συζήτηση: πλήρες run αμερικανικής αγοράς

Ημερομηνία σημείωσης: 2026-09-21. **Δεν έχει προγραμματιστεί ούτε ξεκινήσει νέο run.** Το ξεκινάμε μόνο αφού το συζητήσουμε ξανά και το μηχάνημα έχει ξεκουραστεί.

## Τωρινή κατάσταση

- Η διόρθωση του κώδικα έχει περάσει στο `main` (commit `3041c53`). Η μελλοντική εταιρική έρευνα δεν έχει όριο τιμής (`scan.max_price: null`) ούτε όριο πλήθους συμβόλων (`universe.max_symbols: 0`).
- Ο χρονολογημένος κατάλογος της 2026-09-04 έχει 13.155 εισηγμένους τίτλους, μαζί με ETF και άλλους μη εταιρικούς τίτλους. Το dashboard περιλαμβάνει επίσης ένα ticker του νεότερου run που δεν υπάρχει σε εκείνο το στιγμιότυπο.
- Το παλιό run `full_research_20260920_170826` εξέτασε 5.026 επιλέξιμα εταιρικά σύμβολα, κράτησε 68 και είχε ακόμη όριο $8. Δεν αποτελεί δοκιμή της νέας ρύθμισης.
- Η πλήρης ταξινόμηση καταλόγου και η θεμελιώδης ανάλυση εταιρειών είναι διαφορετικές εργασίες. Το νέο routing επεξεργάζεται κάθε εισηγμένο σύμβολο, αλλά εφαρμόζει εταιρικά θεμελιώδη μόνο στους κατάλληλους εταιρικούς τίτλους.

## Πριν από νέο run

1. Επιβεβαίωση ότι το μηχάνημα είναι διαθέσιμο και ότι δίνεται εκ νέου εντολή για εκκίνηση. Καμία αυτόματη εκτέλεση αύριο.
2. Έλεγχος/επισκευή του απομονωμένου Python runtime `.venv-next` και των αναγκαίων εξαρτήσεων. Ο launcher πλήρους run το απαιτεί· η τωρινή εγκατάσταση πρέπει να επαληθευτεί πριν ξεκινήσει πολύωρη εργασία.
3. Ανανέωση και συμφωνία των πηγών SEC/Nasdaq Trader, με ημερομηνία και πλήθος συμβόλων ανά τύπο τίτλου και χρηματιστήριο. Να ελεγχθεί η διαφορά του πλήρους καταλόγου από το εταιρικό σύνολο που μπορεί να αναλύσει το pipeline.
4. Προέλεγχος ρυθμίσεων: χωρίς όριο $8, χωρίς cap συμβόλων, χωρίς αυθαίρετους αποκλεισμούς (ιδίως tickers όπως PANW/MU και ονόματα όπως United/Aerospace). Καταγραφή αιτιών εξαίρεσης για μη εταιρικούς τίτλους.
5. Μία ελεγχόμενη εκτέλεση εκτός του session του βοηθού, μόνο για έρευνα. Χωρίς trader/order execution. Μία ειδοποίηση όταν τελειώσει, χωρίς βρόχους παρακολούθησης ή περιοδικά checks.

## Πρόοδος προετοιμασίας — 2026-09-21

- Ανακατασκευάστηκε το απομονωμένο `.venv-next` με Python 3.12.14 και εγκαταστάθηκε το
  hashed Windows lock χωρίς dependency conflicts.
- Ανανεώθηκαν επιτυχώς και οι τρεις πηγές Nasdaq Trader/Nasdaq. Το νέο ημερήσιο snapshot
  περιέχει 13.224 εισηγμένους τίτλους και 37 test issues που αποκλείστηκαν.
- Ανανεώθηκε το SEC company universe: 5.521 επιλέξιμα εταιρικά σύμβολα πριν από scoring.
- Προστέθηκε αναγνώριση του exchange code `F` ως Texas Stock Exchange.
- Προστέθηκε fail-closed `full_research_preflight.py` και κλήση του από τον background
  launcher. Το run παραμένει μη εκκινημένο μέχρι νέα ρητή εντολή.
- Προστέθηκε `registry_all_listed` universe mode. Και τα 13.224 σύμβολα λαμβάνουν υποχρεωτικό
  research route: εταιρική θεμελιώδης έρευνα ή κατάλληλη λωρίδα παρατήρησης τίτλου.
- Ο launcher ανανεώνει και συμφωνεί Nasdaq/SEC/catalog/routes πριν από το preflight. ETF,
  warrants, preferred, SPAC, units, debt, rights και ETN παραμένουν ορατά με αποθηκευμένη
  κατάσταση επεξεργασίας και δεν προωθούνται λανθασμένα στο εταιρικό workflow.
